# Taqwa Tours Style Bootstrap Website - Clean Version

This is the readable/clean version of the static frontend project.

## Folder Structure

```text
taqwa-clean-bootstrap/
│
├── index.html
├── about-us.html
├── contact.html
├── umrah-packages.html
├── ...other HTML pages
│
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── img/
        ├── logo.svg
        ├── hero.svg
        ├── hotel.svg
        ├── package.svg
        └── team.svg
```

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3
- Font Awesome 6
- Plain JavaScript

## How to Edit

1. Open `index.html` for the homepage.
2. Edit all custom design rules in `assets/css/style.css`.
3. Edit JavaScript only in `assets/js/main.js`.
4. Images are inside `assets/img/`.
5. Bootstrap and Font Awesome are loaded by CDN.

The HTML has been formatted with proper indentation so sections are easier to find and edit.
